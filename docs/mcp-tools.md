## Descriptions

- `swarms_run`: Launch a Swarms run within a USD budget, wait for it to close and return its outputs.
- `swarms_run_launch`: Launch a Swarms run within a USD budget.
- `swarms_run_get`: Read a run snapshot.
- `swarms_run_wait`: Wait until a run closes.
- `swarms_run_events`: Read one page of ordered run events after a cursor.
- `swarms_run_cancel`: Cancel a run.
- `swarms_run_outputs`: List a run's outputs.
- `swarms_run_output_get`: Read one output record.
- `swarms_runs_list`: List runs, newest first.
- `swarms_project_create`: Create a launch-enabled project.
- `swarms_project_get`: Read one project.
- `swarms_families_list`: List the launchable program families.
- `account_get`: Read the caller's org, principal and limits.
- `account_billing_balance`: Read the wallet balance in microcents.
- `account_billing_history`: List balance movements (ledger entries), newest first.
- `account_billing_plans`: List plans.
